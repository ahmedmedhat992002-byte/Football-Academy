PostgreSQL Schema & Security

Relational Schema with Non-Recursive RLS Policies

📊 8 Core Relational Tables

Engineered schemas for profiles, groups, players, sessions, attendance, evaluations, subscriptions, and notifications.

🛡️ Fortified Row-Level Security

Strict access boundaries: parents view their registered children, coaches view assigned groups, and admins audit the whole academy.

⚡ Recursion-Free Optimization

Eliminated circular policy references between groups and players tables for instantaneous 200 OK query performance.

💾 Resilient Dual Synchronization

Seamless bridge between cloud Supabase data and failover caching ensuring 100% platform uptime.
